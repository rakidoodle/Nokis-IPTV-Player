# Global search

The search box in the main header searches the catalog already loaded for all profiles. Enter at least two characters to find:

- Live channels
- Movies
- Series
- Episodes whose series details have been loaded
- Live TV, movie, and series categories

Typing waits 300 milliseconds before starting a search. A new keystroke cancels the obsolete query. Matches at the beginning of a title rank before matches elsewhere in the title, with alphabetical ordering inside each rank. The window displays at most 50 results so a large provider catalog remains responsive.

Use **Tab** to move into the result popup, then **Enter** or **Space** to open a result. Live-channel results open Live TV and select the channel. Movie results open Movies; series and episode results open Series. Category results open their matching content page.

Search uses names and stable catalog identifiers only. It does not index, display, or log stream URLs, passwords, bearer tokens, or complete provider request addresses. The current catalogs are in memory, so reconnect a profile after restarting the application before searching its content.
